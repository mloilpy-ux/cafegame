LUNYA // NEON CAFÉ — Android edition

В проект встроены все 119 медиа-файлов из двух загруженных архивов: персонажи, игровые арт-доски, изображения и видео. Игра имеет экран меню, кафе, управление заказами, улучшения, настройки и артбук.

APK: в текущем окружении отсутствуют Android SDK / AAPT / D8 / Gradle, поэтому финальный бинарный APK здесь собрать нельзя. Проект готов для Android Studio: открыть папку проекта и выполнить Build > Build APK(s).
